# Bot Desk — prototype UI

Maquette interactive pour piloter les bots WhatsApp (`botpdg`, `botpdg2`, …).

**Pas branché aux vrais bots** — données mock pour valider le design.

## En ligne

GitHub Pages (après deploy) : `https://dazbot13-boopt.github.io/botdesk-proto/`

## Local

Ouvre `index.html` dans le navigateur, ou :

```bash
python3 -m http.server 8080
```

## Écrans

- Vue d’ensemble (statut, metrics, flux)
- Contrôles (toggles)
- Pairing (code mock)
- Config
